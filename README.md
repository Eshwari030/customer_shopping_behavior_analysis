# customer_shopping_behavior_analysis
Data analysis project showcasing  customer behavior analysis using Python, SQL and PowerBI

📊 Customer Shopping Behaviour Analysis

🔍 Overview

This project focuses on analyzing customer shopping behavior using end-to-end data analytics techniques. The goal is to extract meaningful insights from raw data and present them through interactive dashboards and reports to support business decision-making.

📁 Dataset

Source: Excel file containing customer transaction data
Data includes:
Customer details
Product categories
Purchase amounts
Discounts and sales information
The dataset was loaded into Python for preprocessing and analysis

🛠️ Tools & Technologies

Python (Pandas, NumPy, Matplotlib, Seaborn)
MySQL (for querying and data analysis)
Power BI (for dashboard creation)
Excel (data source)
Gamma (for presentation creation)

⚙️ Project Workflow / Steps

Data Loading-
Imported Excel dataset into Python using Pandas

Data Cleaning-
Handled missing values
Removed duplicates
Corrected data types
Fixed inconsistencies

Exploratory Data Analysis (EDA)-
Analyzed sales trends and patterns
Identified top products and categories
Studied customer purchasing behavior
Visualized key insights using charts

SQL Analysis (MySQL)-
Loaded cleaned data into MySQL
Performed queries such as:
Top-selling products
Revenue analysis
Discount impact

Customer segmentation-
Dashboard Creation (Power BI)
Built interactive dashboard with KPIs
Included filters for dynamic analysis
Visualized revenue, sales trends, and customer insights
Reporting & Presentation
Created a detailed report summarizing findings
Designed a professional presentation using Gamma

📊 Dashboard Highlights
Total Revenue and Sales KPIs
Top Performing Products and Categories
Customer Purchase Trends
Discount vs Sales Analysis
Interactive filters for better insights

📈 Results & Insights
Identified high-revenue product categories
Observed customer buying patterns and peak sales periods
Analyzed the impact of discounts on sales performance
Provided actionable insights for improving sales strategy
